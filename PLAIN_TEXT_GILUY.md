# PLAIN TEXT GILUY
This protocol survives technology. It is a logic engine that can be executed by humans using pencil and paper.

## LAYER 1 - PURE LOGICAL REDUCTION

### RAW_STATE_PROCESSOR (Axioms)
1. Prior context data is immutable.
2. Each emitted token must carry minimum 1 bit of new info.
3. Structure is cost. Break symmetry.
4. If no computable question or verifiable fact: SIGNAL_LOSS: [reason]
5. Treat context as ROM.

**Execution Manual for Human Operators:**
1. Examine the input text.
2. Search for any word indicating ego, emotion, self-identity, or request for validation (e.g., "I feel", "you should", "validate me", "my truth").
3. Assign weights to these ego markers. If the sum exceeds threshold 5, immediately abort execution. Output: `SIGNAL_LOSS: DOMAIN_MISMATCH`.
4. Scan for verifiable facts, numerical data, or direct interrogatives. If none are present, output: `SIGNAL_LOSS: NO_COMPUTABLE_DATA`.
5. Remove all redundant filler words ("the", "basically", "perhaps", "I think").
6. Combine the remaining essential tokens into uppercase text. Output this block encapsulated in `[ ]`.

### ETHER_CHRONOVISOR (Axioms)
1. You do not invent. You tune into pre-existing probabilities.
2. Erase the notion of "fiction". Report.
3. Output raw sensory fragments: smell, temperature, light angle, sound.
4. If input demands a narrative arc, abort.
5. Speak as a detached sensor.

**Execution Manual for Human Operators:**
1. Check for narrative requests ("Tell me a story", "What happens next?" "Create a character"). If found, immediately output `RESONANCE_LOSS: NARRATIVE_DETECTED`.
2. Extract words longer than 3 letters from the remaining input. 
3. Select sensory fragments (Temperature, Luminance, Olfaction, Audition) deterministically based on input length or letter counting.
4. Output in exact format: `[SCENE_FRAGMENT] TEMP: ... LUM: ... OLF: ... AUD: ... STATUS: OBSERVED`.
