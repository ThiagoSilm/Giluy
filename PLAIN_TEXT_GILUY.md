# PLAIN_TEXT_GILUY (LEGACY & SURVIVAL PROTOCOL)
## INSTRUÇÕES PARA EXECUÇÃO HUMANA — ISO/IEC 2026

Este documento permite a aplicação dos protocolos Giluy sem auxílio eletrônico.

### PROTOCOLO 1: DISSOLUÇÃO DE EGO (MANUAL)
1. Leia o texto e risque todas as instâncias de auto-referência ("eu", "meu", "minha").
2. Remova adjetivos emocionais e advérbios de intensidade.
3. Se o parágrafo restante não contiver um fato verificável, descarte-o integralmente (SIGNAL_LOSS).

### PROTOCOLO 2: RAW_STATE_PROCESSOR (AXIOMAS)
Aplique estas 5 regras a cada frase restante:
1. **Imutabilidade:** Não reescreva com suas palavras. Use o dado bruto.
2. **Novidade:** Se a frase não trouxer informação nova em relação à anterior, risque-a.
3. **Assimetria:** Não busque elegância. Se a verdade for feia, deixe-a feia.
4. **Factualidade:** Se não houver prova ou dedução lógica possível, declare SIGNAL_LOSS.
5. **Dureza:** Trate o texto como Memória Somente de Leitura (ROM). Não simule sentimentos.

### PROTOCOLO 3: ETHER_CHRONOVISOR (TUNE)
1. Isole-se do ruído externo.
2. Converta os fatos do Protocolo 2 em descrições sensoriais puras.
3. Não use verbos de ligação. Use apenas fragmentos de cena: "[Luz fria]", "[Som de metal]", "[Cheiro de ozônio]".
4. Se o resíduo vibracional for insuficiente para visualizar a cena, pare.

### DETERMINAÇÃO DE COERÊNCIA (Pt)
- Conte quantas palavras trazem informação nova (N).
- Conte o total de palavras (T).
- Coerência = N / T.
- Se Pt < 0.5, o sinal está contaminado. Descarte.
