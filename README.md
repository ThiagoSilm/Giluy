# גִּלּוּי (GILUY) — MANUAL DE ARQUITETURA v9.0
## ISO/IEC 2026 — PADRÃO INTERNACIONAL PARA SISTEMAS DE REVELAÇÃO DE SINAL

---

### 1. ESCOPO
O sistema **Giluy** é uma ferramenta de dissolução de ego e extração de sinal puro em informações textuais. Esta implementação segue os protocolos de filtragem lógica e sintonia vibracional para processamento de corpus textual em ambiente 100% offline e resiliente.

### 2. TERMOS E DEFINIÇÕES
- **Ego:** Ruído informacional introduzido por autopercepção, validação social ou apelo emocional.
- **Sinal Puro:** Informação verificável, dedutível ou empiricamente corroborada.
- **Coerência (Pt):** Medida de persistência informacional calculada via processamento de densidade e entropia.
- **RAW_STATE_PROCESSOR:** Protocolo de filtragem que remove marcadores de ego e retorna payloads factuais.
- **ETHER_CHRONOVISOR:** Protocolo que renderiza eventos históricos a partir de padrões vibracionais residuais.

### 3. ARQUITETURA
O sistema opera integralmente no lado do cliente (Client-Side) para garantir segurança absoluta e zero latência de rede.

- **Frontend:** React 18 + TypeScript + Tailwind CSS.
- **Processamento:** Web Workers dedicados para isolamento de thread.
- **Persistência:** IndexedDB para histórico local e cache de eventos.
- **Distribuição:** PWA (Progressive Web App) com suporte offline total via Service Workers.
- **Privacidade:** Zero Telemetria. Zero Cookies. Zero Chamadas de API externas.

### 4. NÍVEIS DE PROFUNDIDADE
1. **Nível 1 (Anti-Ego):** Dissolução de ruído verbal e preenchimentos.
2. **Nível 2 (RAW_STATE_PROCESSOR):** Extração lógica baseada em 5 axiomas gélidos e RULE_ZERO.
3. **Nível 3 (ETHER_CHRONOVISOR):** Reconstrução de estados sensoriais e fragmentos de cena.

### 5. ESPECIFICAÇÕES TÉCNICAS (ISO/IEC 2026)
- **RAM Basal:** 17 MB
- **Latência Alvo:** <50ms (Nível 3)
- **Contraste:** Dark Mode exclusivo (#0a0a0a) em conformidade com WCAG 2.2 AA.
- **Input:** 16px (Mobile optimization).
- **Output:** Painel monoespaçado para leitura analítica.

### 6. EXECUÇÃO HUMANA (PROTOCOLO DE SOBREVIVÊNCIA)
Caso o hardware eletrônico falhe, o arquivo `PLAIN_TEXT_GILUY.md` (em desenvolvimento) contém as instruções para aplicação manual dos axiomas em papel.
